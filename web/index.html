Red Alert in your browser. Rust, WebAssembly and WebGPU.

Skirmish

Stress test

Two armies attack-move into each other. Shows how many units the WebAssembly simulation and flow fields can handle.

Controls
  • Left click select; with units selected, left click gives the order (move, attack, harvest, dock, repair)
  • Drag box select (only combat units when the box has any), double click all of that type on screen
  • Right click clears the selection. A selected factory: left click the ground to set its rally point
  • A then click: attack-move. S stop. Esc cancel
  • Ctrl+1..9 make group, 1..9 select group
  • Numpad 1..9 build that sidebar card (Shift: 5, Ctrl: cancel), Numpad +/-/0 switch tabs
  • Arrow keys, screen edges or middle drag to pan, wheel to zoom, H/Space base
  • Sidebar: click to build (shift: 5), right click to cancel, click a finished building to place it
